qchorder

The Suzuki Q-Chord provides a basic but rather inconvenient MIDI Out interface. This web utility converts the outgoing signal from the Q-Chord into more standard MIDI messages that can be forwarded further into DAWs.

Input

This is where the MIDI device corresponding to your Suzuki Q-Chord should be selected. The web utility will process all messages coming from this device.

Output

The "corrected" MIDI signal will be forwarded to this MIDI device, on the selected channel.

Settings

Here you can finetune how the Q-Chord MIDI messages are processed. Well, you will soon be able to.

So what is this about? The Suzuki Q-Chord MIDI mapping is somewhat convoluted. As you may know, the strumplate is divided into 4-ish sections for each octave. On each of those sections, the three notes of a selected chord can be played individually. Rather than generating a single "Note On" MIDI message for every note that is played on the strumplate, the Q-Chord separates this information over 3 distinct MIDI channels. The bottom notes of a chord, for any octave, are played on channel 14. The middle notes on channel 15, and the high notes on channel 16. Additionally, such "Note On" messages do not contain the actual note that is being played, but always the C of the current octave. Instead, a "Pitch Bend" message is sent on the three channels every time a new chord is selected on the Q-Chord.

This tool does the trivial translation of merging those 3 channels into one, and processing the pitch bend information so that "Note On" messages contain the actual note that is being played.
